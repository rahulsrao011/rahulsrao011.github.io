This is my new home on the internet. I'll use it to write about things I'm building, problems I've run into, and whatever else seems worth sharing.

## How this site works

Every post here is just a plain text file written in Markdown. To publish something new, I create one file, write, and push. No HTML, no build step on my end — GitHub handles the rest.

Here's what a post looks like under the hood:

```markdown
---
title: My post title
subtitle: An optional one-line summary.
tags: [example]
---

Your writing goes here. **Bold**, *italics*, [links](https://example.com),
lists, code blocks, and images all work.
```

That's the whole thing. More soon.
